# PicPilot AI MVP

PicPilot AI 是一个面向电商卖家和小微商家的 AI 商品图与营销图生成平台 MVP。

## 已实现

- 深色科技感品牌首页
- 商品图上传与本地预览
- 商品名称、卖点、促销信息填写
- 场景与视觉风格选择
- 4 张 SVG 营销图候选生成
- 轻量在线编辑器
- SVG 下载导出
- 品牌资产中心与后续路线展示

## 本地运行

无需安装依赖，直接打开：

```text
index.html
```

也可以用任意静态服务托管整个目录。

## 当前限制

- 当前生成是前端 SVG 模拟，不是真实图像模型生成。
- 当前未接入抠图、登录、支付、云存储和后端任务队列。
- 当前环境缺少 git 命令，暂时无法自动提交和推送到 GitHub Pages。

## 下一步

1. 安装并配置 Git。
2. 创建 GitHub 仓库。
3. 推送 `picpilot-ai/` 到仓库。
4. 启用 GitHub Pages 或部署到 Vercel。
